Cisco Secure Client 5 新增功能

🔐 Cisco Secure Client 5.1.17.3382 新特性 (01-May-2026)

本版本包含以下新增更新，并修复了已知问题。

  • Linux x64（仅 GUI）支持 Zero Trust Access — 该支持引入了 DEB/RPM 软件包安装程序，以及 DART 更新（日志和崩溃转储）。
  • Endpoint Data Loss Prevention（端点数据防泄露）支持与部署（仅限 Windows 预部署） — 通过控制数据向外部设备的传输来保护端点上的敏感数据。该功能扩展了组织的数据保护策略，并确保敏感数据始终安全且符合安全要求。
  • 启用 FIPS 模式时，所有不提供前向保密（Perfect Forward Secrecy）的基于 RSA 的密码套件将从支持列表中移除。此外，提供前向保密的 ECDH 和 MODP 组仍受支持，并在 FIPS 模式下作为首选密钥交换机制。
  • ISE Posture 持续重新评估（Continuous Reassessment） — 提供接近实时的端点姿态监控。对于基于事件的条件，可在变化发生时立即检测 (sysin)；对于轮询条件，每 10 分钟检测一次。不会造成网络中断，也无需等待下一次计划的重新评估周期（周期性重新评估）。持续重新评估仅支持 Cisco Secure Client 完整代理（Full Agent），不支持无代理（Agentless）和临时代理（Temporal）。
  • macOS 客户端部署文档变更（CSCwt95756） — Secure Client 在 macOS 上的部署方式已发生变化，无论是否使用客户端管理。
  • 版本 5.1.17.3382 包含以下各模块版本：
    • Zero Trust Access — 5.1.17.5300
    • Secure Client UI — 5.1.17.1876
    • Cisco AnyConnect VPN 核心 — 5.1.17.3382
    • DART — 5.1.17.3382
    • Umbrella — 5.1.17.3382
    • SBL — 5.1.17.3382
    • Network Access Manager — 5.1.17.3382
    • Network Visibility Module — 5.1.17.3382

    • ThousandEyes — 2.35.0

    • CSCwu08657 — macOS：使用 CiscoSSL8 默认 PKCS12 格式时，SCEP 证书导入存在问题

文件描述

Cisco Secure Client 可通过以下方式部署给远程用户：

  • 预部署（Predeploy）：新的安装或升级可以由最终用户完成，或通过企业软件管理系统（SMS）进行。
  • Web 部署（Web Deploy）：AnyConnect 软件包会加载到头端设备上，该设备可以是 ASA 或 FTD 防火墙，或者是 ISE 服务器。当用户连接到防火墙或 ISE 时，AnyConnect 会被部署到客户端。

The Cisco Secure Client can be deployed to remote users by the following methods:

  • Predeploy - New installations and upgrades are done either by the end user, or by using an enterprise software management system (SMS).
  • Web Deploy - The AnyConnect package is loaded on the headend, which is either an ASA or FTD firewall, or an ISE server. When the user connects to a firewall or to ISE, AnyConnect is deployed to the client.
