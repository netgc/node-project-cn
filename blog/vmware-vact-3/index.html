vDefend and Avi Conversion Tool

vDefend and Avi Conversion Tool（vACT）是一款自动化迁移实用工具，通过将传统或第三方负载均衡器配置转换为 VMware Avi Load Balancer 对象，并将第三方安全数据转换为原生 vDefend 分布式防火墙策略，从而减少手动重新配置的工作量。

面向 Avi 负载均衡器的转换工具

vDefend and Avi Conversion Tool (vACT) 是一款迁移和转换解决方案，可减少将工作负载从传统或第三方负载均衡器迁移到 Avi Load Balancer 的工作量。从 3.0.0 版本开始，Avi Conversion Tool (ACT) 正式更名为 vDefend and Avi Conversion Tool (vACT)，并新增了将托管在 Illumio 上的安全类解决方案转换为 vDefend 防火墙的功能。

您可以直接在 vACT UI 中选择 Illumio Migration 卡片，利用自动化工作流将 Illumio 配置无缝转换为 vDefend 安全策略和组。

vACT 会获取您当前的负载均衡器或入口（ingress）配置，并生成等效的 Avi 配置以及（在受支持的情况下）基于 Gateway API 的配置，使您在切换期间能够保持正常运行时间并减少手动重新配置。

vACT 的功能：

  • 将受支持来源的配置转换为 Avi 控制器对象（虚拟服务、池、健康监视器、策略及相关对象），对于 Kubernetes 入口，则转换为 Gateway API 清单和 Avi/AKO CRD。
  • 对于安全迁移，它会将 Illumio 数据转换为 NSX 兼容的 CSV，以便在 vDefend 中自动创建 VM 标记、组、服务、上下文配置文件和分布式防火墙（DFW）策略。
  • 支持多种迁移路径：F5 BIG-IP LTM、NSX-T、NSX Data Center（负载均衡器）、vSphere Supervisor 中基于 NSX 的负载均衡器，以及 NGINX Ingress Controller 配置到 Gateway API 格式。
  • 支持将安全策略从 Illumio 迁移到 vDefend。
  • 提供可直接使用的 YAML/JSON 以及转换状态报告，便于您查看哪些内容已转换、哪些被跳过或不受支持。
  • 提供摘要仪表板和可下载的执行日志，用于排查安全迁移期间策略实现失败的问题。

何时使用 vACT：

当您要将 Avi 引入已使用 F5、NSX 或 NGINX Ingress 的环境，或者希望统一采用 Avi 和 Gateway API 时，请使用 vACT。此外，当您要将安全基础设施从 Illumio 过渡到 vDefend 时，也可使用 vACT。

本指南的其余部分将介绍如何部署 vACT 并运行各个迁移工作流。

面向 vDefend 的转换工具

​vDefend and Avi Conversion Tool (vACT) 提供了易于使用的界面，可将安全策略和清单对象从传统 Illumio 环境无缝转换并迁移到相应的 VMware vDefend NSX 部署。它可自动将配置文件转换为 NSX 就绪格式，使管理员能够在正式执行强制策略之前，安全地暂存、验证和回滚分布式防火墙（DFW）策略。

从 Illumio 迁移到 vDefend：

vDefend and Avi Conversion Tool (vACT)，这是一个基于 Go 的自动化工具包，用于将安全策略和工作负载迁移到 VMware® vDefend™。

该迁移工具旨在帮助将安全策略、工作负载标签和网络分段规则从 Illumio 策略计算引擎（PCE）迁移到 VMware® vDefend™ 分布式防火墙。它与 vACT 身份验证框架集成，用户只需登录一次，即可无缝访问迁移器，无需单独登录。

为什么使用迁移工具？

将您的零信任架构从 Illumio 无缝过渡到 VMware® vDefend™。该工具专为基础设施整合和现代化项目而构建，以可靠的自动化工作流取代了高风险、耗时的手动流程。在不影响现有策略定义的前提下，加快您的部署进度。

该工具的功能？

该迁移工具通过以下几项关键功能来应对迁移的复杂性：

  • 将 Illumio 基于标签的策略模型转换为 vDefend 基于标记和组的模型。
  • 自动将 Illumio 的离线导出内容（IP 列表、规则、工作负载、标签组和服务）转换为 vDefend 兼容的 CSV 格式。
  • 通过 REST API 自动创建 vDefend 策略，包括组、服务、安全策略和规则。
  • 执行 VM 标记，用于工作负载识别和策略强制执行。
  • 通过专用验证层确保数据完整性、实现状态和策略正确性。
  • 通过内置的回滚和清理功能，支持安全地测试和删除已迁移的对象。
  • 提供基于 Angular 的 Web 用户界面，提供带有实时进度跟踪的引导式迁移工作流。
  • 同时支持本地管理器（Local Manager）和全局管理器（Global Manager）迁移。

Illumio 迁移的关键设计原则：

  • 默认禁用：所有已迁移的规则（包括默认拒绝和选择性允许的终止规则）均以禁用状态创建（disabled: TRUE）。运维人员必须在查看环境就绪情况后逐条启用规则。
  • 规则级范围限定：所有安全策略对象均被分配 DFW 范围的 [“ANY”] 作用域。规则集的范围由每条规则的“应用于”（applied-to）字段在规则级别严格强制执行。
