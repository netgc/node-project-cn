Omnissa Access

通过 SSO、MFA 以及与领先的 IDP 集成，无缝地验证用户身份、减少攻击面并保护公司数据。

​

产品优势

数字工作空间的身份解决方案

  • 通过条件访问保护您的环境

    通过基于设备状态、用户行为和位置的条件访问来保护公司资产。

  • 平衡用户体验和安全性

    在最终用户需要时为他们提供所需的内容，同时实时定制访问权限和管理风险。

  • 与身份和安全生态系统集成

    轻松与领先的 IDP 集成，实现交钥匙配置和管理。将安全信号纳入访问决策中。

功能特性

为什么选择 Access？

  • 访问代理

    与领先的身份提供商集成，以减少部署时间并支持更安全地访问任何应用程序。

  • 自适应多因素身份验证 (MFA)

    提供本机 MFA 或与现有 MFA 提供商集成，以更好地保护对应用程序和数据的访问，并为最终用户提供低摩擦体验。

  • 单点登录 (SSO)

    通过与 Omnissa Workspace ONE® Intelligence Hub 集成，提供对 Web、SaaS、移动和旧版应用程序的单点登录。

  • 基于风险的条件访问

    创建和实施利用设备注册、网络、用户行为、位置以及第三方安全信号和信息的访问策略。

使用案例

解决您最棘手的挑战

在不影响安全性的情况下提供对应用程序和数据的一致访问具有挑战性。 Omnissa Access 可以提供帮助。

  • 启用零信任

    平衡风险并持续验证设备、用户和应用程序上下文，以提供对公司资源的最低权限访问。

  • 加速应用程序部署

    提供对任何设备上任何应用程序的本质安全、有条件的访问。通过基于复杂身份、设备和应用程序组合的代理访问来加快部署时间。

  • 单点登录

    持续验证用户、设备和登录上下文，以提供高度安全的单点登录并提高员工工作效率，同时保护公司资产。

新增功能

Omnissa Access 24.12 是一个常规维护版本，包括品牌和安全相关更新、连接器更新和其他产品修复。

重要信息 - 仅升级版本：Omnissa Access 24.12 仅可作为版本 24.07 的升级版本。不支持全新安装 Omnissa Access 24.12 虚拟设备。

  • Horizon 应用程序启动 URL 更改：作为向新公司 Omnissa 过渡以及相关品牌更改的一部分，用于从 Intelligent Hub 门户或应用程序启动 Horizon 应用程序的启动 URL 已更改。为了支持这一更改，我们在 Omnissa Access 控制台中引入了一个新选项，即通过 Omnissa URL 启用 Horizon Client 。

    默认情况下，取消选择启用 Horizon Client 与 Omnissa URL选项。默认设置同时支持旧版和新版启动 URL，这意味着除了新版 24.12 之外，您还可以继续使用旧版 Horizon Client（例如 24.06）。

    启用使用 Omnissa URL 启用 Horizon Client选项后，应用程序启动将使用新的启动 URL。仅 Horizon Client 版本 24.12 及更高版本支持新 URL。对于早期的 Horizon Client 版本，应用程序启动将失败。

    注意：通过 Omnissa URL 启用 Horizon Client选项适用于 Horizon 与 Omnissa Access 的本地集成。

  • 操作系统更新：虚拟设备操作系统已升级至 Photon 5。

Omnissa Workspace ONE Tunnel 用于跨所有员工的设备安全地提供每应用程序或完整设备 VPN 功能，并通过现代零信任架构交付。它是 AnyWhere Workspace 解决方案集的一部分，用于实现远程工作和强制端点合规性。Workspace ONE Tunnel 解决方案提供对工作应用程序和公司资源的安全访问。

用户将获得简单的按需体验，无需与 Workspace ONE Tunnel 进行任何交互。您的组织将能够提供轻松的入职服务，无需停机，因为您知道只有定义的应用程序和域才能访问其网络。它允许 IT 专业人员和 Workspace ONE UEM 管理员轻松定义特定于每个应用程序的精细流量策略。为了获得最佳安全性，隧道基于 TLS 1.3 构建，具有证书固定和身份验证功能。
