Qt Creator IDE：让 Qt 开发更简单

最适合 Qt 的集成开发环境（IDE）。Qt Creator IDE 提供覆盖完整开发周期的跨平台工具，帮助你快速上手、高效协作，并持续交付高质量成果。

  • 完整的 QML 支持

  • AI 智能辅助

  • 跨平台部署

产品概述

使用 Qt Creator 持续高效交付

Qt Creator IDE 提供覆盖多平台的完整软件开发生命周期工具。通过模板和示例快速启动项目 (sysin)，轻松理解甚至是继承而来的代码，并在整个项目周期中实现跨职能协作。

  • 对 Qt 的全面支持

    提供业内领先的开发体验，并为 QML 与 C++ 提供开箱即用的强大支持。

  • 迭代式嵌入式开发

    为多种主机与目标平台提供出色的嵌入式开发支持。

  • 覆盖完整开发周期的工具

    提供丰富的工具，用于项目管理、编码、调试、测试以及部署。

最适合 Qt、QML 与 C++ 的 IDE

开箱即用的支持。

Qt Creator IDE 在整个软件开发生命周期中，为使用 Qt Framework 的跨平台项目（从小型到超大型）提供一流的开发体验。

主要亮点包括：

  • 面向 QML 和 C++ 的语言服务器
  • 高效的 QML 与 C++ 重构能力
  • 出色的 Qt 类检查能力
  • QML 性能分析 (sysin)
  • 与 Qt 文档和示例的深度集成
  • Qt 项目模板，助你快速上手

享受图形加速带来的流畅体验

跨平台高效性。

无论你是在启动第一个嵌入式项目，还是面对陌生硬件的新项目，Qt Creator IDE 都能帮助你快速进入开发状态。

通过以下特性提升嵌入式开发效率：

  • 支持广泛的目标设备：涵盖多种架构、开发板和操作系统，
  • 快速、简便的开发环境配置，
  • 高度自动化的设备部署，用于单元测试；只需选择 Qt 版本和设备即可构建。

你还可以使用经过 Qt 优化、与硬件无关的 BootToQt。它是一个轻量级、完整的软件栈 (sysin)，适用于嵌入式 Linux 系统。

使用 Qt AI Assistant 提升生产力

现成的构建模块。

Qt AI Assistant 帮助开发者专注于最热爱的事情：编程。将时间从编写测试用例、代码文档和样板 QML 代码等辅助任务中解放出来。

  • 可选的自动补全
  • 代码解释、重构与优化
  • 开放访问你喜爱的各类大语言模型（LLM）
  • 自动生成单元测试和文档 (sysin)

覆盖整个开发周期的交付能力

  • 编码、调试与性能分析

    顺畅地编写、编辑和导航源代码。通过代码补全、语法高亮和 AI 辅助提升效率。借助 QML 与 C++ 的语言服务器，快速掌握甚至是继承代码。使用代码检查、重构和本地化工具，高效调试和分析代码（包括 QML）。

  • 创建与管理项目

    实现跨职能协作。以多种格式创建和管理项目。使用你偏好的构建系统（如 CMake）和版本控制系统（如 Git），并进行多种形式的代码评审。

  • 单元测试与代码分析

    将测试作为开发周期的一部分来编写和运行。支持 Qt Test、Boost.Test、Catch2 或 Google C++ 等测试框架。无论是测试驱动还是行为驱动开发，都能高效管理测试流程。

  • 部署到目标平台与设备

    将部署自动化集成到测试或开发流程中。高效地将项目部署到多种目标设备和平台，包括 Android、iOS、嵌入式 Linux 等。

Qt Creator IDE 扩展

扩展你的开发能力。

Qt Creator 提供多种 IDE 扩展、插件及其他可选组件，供你按需选择。

这些扩展可增强和扩展 IDE 的能力，为开发带来更高效率，例如 AI 功能、生产力提升、界面视觉优化、与版本控制或构建系统的集成，或对其他编程语言的支持 (sysin)。

不断增长的扩展生态

  • 面向 Qt Creator 用户

    Qt Creator 内置 50+ 插件和扩展，助你从提升效率到增强功能，全方位扩展工作能力。立即发现你的最爱！

  • 面向扩展发布者——封闭测试阶段

    由于 Qt Creator 扩展商店仍在开发中，目前仅限少量发布者申请发布使用 C++ 或 Lua 编写的 IDE 扩展。

新增功能

Qt Creator 21 正式发布

发布时间：2026 年 11 月 23 日

Qt Creator IDE 21 版本让 AI Agent 能够自动执行更多编辑、构建、运行和调试任务，同时您可以更好地控制它们的操作权限，并了解其使用成本。全新的 Profile（性能分析）模式不仅能够告诉您应用程序在哪些地方运行缓慢，还会提供相应的优化建议。

AI 支持

Agentic AI Chat（ACP）集成和 MCP Server 现在默认启用，同时，MCP Server 现在也默认要求使用 Bearer Token 进行身份验证。您在 Qt Creator 的 Agentic AI Chat 中配置的 Agent 会自动处理这一过程，但如果您从外部连接 Qt Creator MCP，则需要添加一个授权请求头 "Authorization: Bearer <token>"，并使用 Qt Creator MCP 设置中的 Token，才能成功连接。您可以通过 Preferences > AI > Qt Creator MCP Server > Require an authentication token 关闭身份验证。

为 MCP Server 添加了许多新工具，并使这些工具都可以在首选项中单独配置。还将 MCP 更新到了 2026-07-28 协议版本。

Agentic AI Chat 也获得了许多改进。来自注册表的 Agent 可以自动更新，并且可以专门针对之前使用过的工作区创建新的会话。如果 Agent 支持，还可以删除会话、将 Agent 切换到新会话，并在聊天界面中查看当前会话和当前轮次的 Token 使用量及成本信息。新增了对 elicitation API 的支持，使 Agent 能够向用户请求结构化信息。此外，还让模式和模型选择功能可以直接从聊天输入框中访问，并支持筛选和收藏功能。

调试与性能分析

全新的 Profile 模式集成了新的 Qt Profiler 工具，用于取代 QML Profiler。全新的仪表板会对各种性能指标进行评分，并针对每项具体发现提供详细信息和修复建议。跟踪记录会作为独立文档打开。Profile 模式还支持在 Windows 和 macOS 上使用 Call-Stack Sampler（调用栈采样器），同时也支持 Qt Tracepoints。可以通过这个 YouTube 短视频 (https://www.youtube.com/shorts/JXN0-s8geMU) 查看实际效果。

新增了一项实验性选项，可以使用一个组合引擎同时调试 C++ 和 QML，并支持组合堆栈跟踪。您可以在运行配置的 Debug 设置中选择 C++ and QML 来启用该功能。

还开发了全新的模块化调试器后端，使其更易于测试。可以通过启用 Preferences > Debugger > General > Use the new debugger backends (experimental) 来体验这些功能。

编辑

新增了 .qdoc 文件编辑器，支持渲染预览，类似于现有的 Markdown 编辑器。同时，它还会在编辑器中以标记形式显示问题。

全新的设置项 Preferences > Text Editor > Display > Check Spelling 可以为代码注释、文本文件和提交消息启用拼写检查。在 macOS 和 Windows 上，该功能使用操作系统提供的功能。在 Linux 上，则需要安装 enchant-2 库。

Git 合并冲突标记现在可以在文本编辑器中以更直观的方式显示，并且可以选择保留当前版本、传入版本或同时保留两个版本。

FakeVim 也获得了大量修复，并新增了对各种 Vim 功能的支持，包括 Vimscript 的很大一部分功能以及插件支持。

版本控制

全新的 Changes 导航视图可以显示已更改的文件，并提供多种操作，例如 Diff、Stage、Revert、Log 和 Annotate。

现在，单个文件的 Diff 会在可编辑的实时 Diff 编辑器中显示。

全新的 Git Log 导航视图可以显示 git log 图形。展开节点后，可以查看对应变更的文件统计信息。右键菜单提供了多种操作，例如查看提交记录或单个文件的变更，以及检出（Checkout）或挑选提交（Cherry-pick）。

项目

将 CMake 解析器更新到了 CMake 4.2 版本。现在可以使用 cm Locator 过滤器执行任意 CMake 命令。为 CMake 文件添加了内置缩进器，可以用它替代 cmake-format；CMake 编辑器现在还支持 Outline 视图和下拉菜单。CMake Presets 新增了面向 Qt Creator 的 runSettings 和 runDevice 供应商扩展，同时也修复了许多问题。

现在，您还可以直接从编辑器中打开的可执行文件创建 Workspace 项目，从而更加轻松地运行和调试该可执行文件。

设备

新增了对 HarmonyOS 的实验性支持。

同时新增了对远程 Windows 设备（通过 SSH 连接）的实验性支持。

此外，还修复了使用 Xcode 27 在 iOS 设备上运行应用程序时遇到的问题；Android 支持新增了 Logcat 视图（Tools > Android > Logcat）；现在可以在 Qt Creator 中使用通过 Podman 管理的容器；还改进了远程路径的文件对话框。

其他

如果您想知道 Extensions 浏览器在哪里：它已经从独立模式移动到了 Preferences 中的一个页面。

Qt Creator 21 还包含许多其他新增功能和改进。有关更详细的信息，请参阅官方文档。

更多详细内容请参阅官方变更日志。
