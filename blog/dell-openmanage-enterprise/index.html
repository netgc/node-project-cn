Dell OpenManage Enterprise

OpenManage Enterprise 系统管理控制台可促进业务增长，提高 IT 生产力并改善客户服务

​OpenManage Enterprise 是一款易于使用的一对多系统管理控制台。它能在一个控制台中经济高效地为 PowerEdge 服务器提供全面的生命周期管理。

OpenManage Enterprise 概览

OpenManage Enterprise 是作为虚拟设备提供的一对多系统管理和监视 Web 应用程序。您可以通过它全面了解企业网络中的戴尔服务器、机箱、存储、其他第三方设备和组件以及网络交换机 (sysin)。它专为新一代 IT 专业人员而设计，专注于简易性、自动化和统一数据中心管理。

借助 OpenManage Enterprise，用户可以执行以下操作：

  • 查找数据中心环境中的设备。
  • 查看硬件资源清册并监测设备运行状况。
  • 查看和管理设备收到的警报并配置警报策略。
  • 监测固件/驱动程序版本。
  • 使用固件基线管理设备的固件/驱动程序更新。
  • 管理设备上的远程任务（如电源控制）。
  • 使用部署模板管理设备间的配置设置。
  • 使用智能标识池管理设备间的虚拟标识设置。
  • 使用配置基线检测和修复设备间的配置偏差。
  • 检索和监测设备的保修信息。
  • 将设备分组为静态或动态组 (sysin)。
  • 创建和管理 OpenManage Enterprise 用户。
  • 备份和还原设备。

OpenManage Enterprise 包含安全功能，例如：

  • 基于角色的访问权限，用于限制对控制台设置和设备操作的访问。
  • 基于范围的访问控制允许管理员限制设备管理者可以访问和管理的设备组。
  • 通过 Security-Enhanced Linux (SELinux) 和内部防火墙加强的设备。
  • 内部数据库中的敏感数据加密。
  • 在设备之外使用加密通信 (HTTPs)。
  • 创建固件和配置相关的策略。
  • 配置以配置和更新裸机服务器。

OpenManage Enterprise 具有基于任务的 GUI，其设计导航时充分考虑主要由管理员和设备管理者使用的任务的顺序。将设备添加到环境中时，OpenManage Enterprise 会自动检测设备属性，将它置于相关的设备组中，并支持您管理设备。

OpenManage Enterprise 的主要优势

  • 作为安全的虚拟设备进行部署
  • 采用直观的控制面板和弹性搜索引擎
  • 通过用户定义的策略、模板和基准，实现一对多智能自动化
  • 借助全面的 RESTful API，实现可自定义的自动化和解决方案集成
  • 通过基于范围的访问控制 (SBAC)，管理员可以将用户限制到特定的设备组

利用 Dell OpenManage Enterprise 为您的 IT 专业人员提供支持

OpenManage Enterprise 旨在消除 IT 基础架构管理的复杂性，取得事半功倍的效果。

​

  • 简化

    通过 HTML5 GUI 和弹性搜索引擎，更加轻松快捷地导航至关键信息和任务。

  • 统一

    管理多达 8,000 台 PowerEdge 服务器并监视网络、存储和第三方设备 (sysin)。从 OpenManage Enterprise 界面查看并控制服务器功耗。

  • 自动化

    从发现到停用，在同一控制台中管理各种活动。借助模板，几分钟内即可自动部署设备。

  • 安全

    检测用户定义的配置模板中是否存在偏差。使用预设置策略，向关键联系人发送警报，并纠正配置错误。

新增功能

OpenManage Enterprise 4.7 新功能

  • 新增 Dell PowerEdge 服务器支持
    • 新增对 Dell PowerEdge R4715、R5715 和 XE9780LAP 服务器的支持。
  • 用户界面升级
    • 用户界面全面升级，提供更快、更灵敏的管理控制台，并带来统一一致的视觉风格和使用体验。
  • OpenManage Enterprise MCP Server
    • Dell OpenManage Enterprise MCP Server 通过模型上下文协议（MCP）将您的 OpenManage Enterprise 设备连接到 AI 聊天界面（Open WebUI）。您可以通过自然语言输入请求来监控和管理 Dell 服务器基础设施。
    • 支持 AI 驱动的服务器管理操作，包括运行状况监控、告警管理、固件合规性检查与更新、配置合规性与修复、电源控制、功耗上限管理、硬件清单、性能监控、日志检索以及任务跟踪等功能。
    • 需要 OpenManage Enterprise 4.7 或更高版本 (sysin)、Open WebUI v0.8.0 或更高版本、已配置 DNS 且 MCP Client 可访问的 FQDN、443 端口网络连通性，以及受信任的 HTTPS 证书。
    • 支持 OAuth 2.1 身份验证（推荐，可实现自动登录和令牌管理）以及基于会话的身份验证（Bearer Token）。
    • 使用与 OpenManage Enterprise Web 控制台相同的 HTTPS 证书。
  • 规模与性能增强
    • 提供性能增强，可监控多达 25,000 台设备。
    • 可收集和查看最多 25,000 台设备的运行指标（如 CPU、内存和网络使用情况），且不会出现性能下降。
    • 将告警容量提升至最高 150,000 条，适用于全新部署和升级部署环境。
  • 基于会话的 Redfish 身份验证
    • 使用基于会话的 Redfish 身份验证替代基本身份验证（Basic Authentication），连接 iDRAC9 及更高版本设备，以执行发现、清单收集、健康检查和固件更新等操作。
    • 如果基于会话的身份验证失败，设备将自动回退至基本身份验证以完成任务。
  • Infrastructure Update Catalog（IUC）集成
    • 支持使用来自 Dell.com 的 Infrastructure Update Catalog 创建和更新固件基线，从而为 Power Shelf 和 Integrated Rack Controller（IRC）设备提供更新支持。
  • GPU 固件更新增强
    • 为 GPU 或加速器固件更新新增“完整电源循环（Full Power Cycle）”重启选项。
    • 提供电源控制功能，通过执行完整的 AC 断电和重新上电流程，支持需要完整电源循环才能完成固件更新的 GPU 组件。
  • Integrated Rack 许可证
    • OpenManage Enterprise 现已支持 Integrated Rack 许可证，可为配备 Integrated Rack Controller（IRC）的机柜提供高级机柜级监控与指标功能。
    • 许可证状态决定额外机柜级属性的可用性。
  • NVL 交换机支持
    • 新增对 NVIDIA N5600 交换机的发现、硬件清单、运行状况监控和告警监控支持。
  • 新增 PDU 支持
    • 支持对 Raritan PX3-4201R 配电单元（PDU）进行监控和电源管理操作。
  • SUSE Linux Enterprise Server 16 支持
    • 新增对 SLES 16 操作系统的发现、清单收集和监控支持。
  • 新增 Power Shelf 支持
    • 新增对 Delta 19 英寸 33kW Power Shelf 的发现、清单收集、监控、告警和机柜管理支持。
  • Integrated Rack 增强可视化
    • 在物理层级分组中增强了机柜级基础设施（Rack Scale Infrastructure）的可视化展示能力。
  • 机柜电源冗余状态指示
    • 为机柜级基础设施提供机柜层面的电源冗余状态显示。
  • 电源负载变化通知
    • 支持在数据中心基础设施中启用高幅度功率波动（Power Swing）通知。
