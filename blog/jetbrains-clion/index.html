CLion 最新变化

CLion 2026.3 搭载了 JetBrains Air，这是 JetBrains IDE 中用于智能体开发的全新层。它还扩展了智能体辅助的嵌入式调试和 CMake 设置，同时新增对 NVIDIA CUDA Tile C++ 和 ISPC 的原生支持。

JetBrains Air in CLion 在一个地方运行智能体并验证其工作成果

自此版本起，JetBrains IDE 随附 Air，这是用于智能体开发的全新层。在 IDE 中运行、跟踪和验证多智能体工作流，代码智能会引导智能体避开常见陷阱，集成的审查工具则让您在每项更改进入代码库之前对其进行检查。

⚙️ 您的智能体，您的模型，您的订阅 – 搭配免费 Junie Lite

Air 可与 Claude Agent、Codex、Gemini、GitHub Copilot、Junie、OpenCode 以及其他兼容 ACP 的智能体配合使用。它会自动检测您机器上已安装的智能体，只需一键即可连接，您也可以从智能体注册表中添加更多智能体。

您现有的工作流可以无缝沿用：提供商订阅、API 密钥和自定义基础 URL 均可使用，无需 JetBrains AI 订阅。您可以在终端或全屏 IDE 标签页中使用您的 Claude 订阅运行 Claude Agent，在聊天或终端中使用其他智能体，并可随时切换订阅，甚至在会话进行中也可以切换。

为帮助您在没有外部订阅的情况下上手，Air 开箱即用地包含由 Junie Lite 提供的免费 AI。您只需要一个 JetBrains 账户。

⚙️ 用于审查更改和指导智能体的中心化工作区

在查看周边代码和项目工具的同时审查智能体的更改，并将反馈直接发回给智能体。将备注锚定到差异中的特定行，或直接在编辑器中评论，为智能体的调整提供具体上下文。您可以在聊天或终端中工作，选择适合您的方式即可。

主要 IDE 变化

⚙️ 硬故障的智能体调试

ARM Cortex-M 芯片上的硬故障（hard fault）表明出现了问题，但很少解释原因。诊断根本原因需要手动解码故障状态寄存器，将出错的程序计数器与反汇编代码进行匹配，而且通常需要多次重现崩溃。

CLion 现在通过专用的 MCP 工具和捆绑的 AI 技能自动完成这项调查工作。您的智能体会检查故障寄存器、内存和反汇编代码，使用与您相同的调试器工具将问题追溯到其源头。该工作流支持 Lauterbach TRACE32、SEGGER J-Link、ST-LINK 和其他调试探针，以及任何连接到 IDE 的 MCP 服务器的智能体。

⚙️ 智能体辅助的 CMake 项目配置

新 CMake 项目可能因为配置文件配置不当或缺少工具链组件而无法加载，确定问题原因可能需要一定的时间。

当 CMake 加载失败时，CLion 现在会显示一个通知，其中包含 Configure with <agent>（使用 [智能体] 配置）按钮。选择您已安装的某个终端智能体，例如 Claude Code、Codex 或 Junie，IDE 会打开其终端，并加载预设的提示词。该智能体会与 CLion 的 MCP 服务器进行交互，以诊断问题、更新您的 CMake 配置文件和工具链，并重新加载项目。

⚙️ 支持 NVIDIA CUDA Tile C++

NVIDIA CUDA Tile C++ 为 GPU 代码引入了基于 tile 的编程模型。它让您能够在整个数据 tile 的层面上编写 GPU 内核，而无需手动协调各个 GPU 线程。尽管 CLion 此前已支持 CUDA C/C++，但 IDE 无法识别 CUDA Tile C++ 语法。

CLion 现在是首批支持 CUDA Tile C++ 的 C++ IDE 之一。它能理解新语法，并在您输入时高亮显示 tile 特有的代码问题，例如不支持的控制流或非正的 irange 步长。该支持适用于以 C++20 和 CUDA Toolkit 13.3 或更高版本为目标的项目。

⚙️ 类内存布局可视化

新增的 Class Layout（类布局）工具窗口可以直观呈现类、结构体或联合体的内存布局。它会显示每个字段和位域、基类子对象、虚表指针的偏移量和大小，以及它们之间的填充。这样可以轻松发现冗余填充，检查 alignas 或 #pragma pack 的效果，并检查复杂层次结构中类的布局。

要打开此窗口，在 macOS 上，请在类型或其用法处按 ⌥↩︎（在 Windows/Linux 上按 Alt+Enter），然后选择 Class Layout（类布局）。

⚙️ 支持 ISPC

Intel SPMD Program Compiler (ISPC) 是一种基于 C 的语言和编译器，用于编写在 CPU 和受支持的 Intel GPU 的 SIMD 向量单元上运行的高性能并行代码。它常用于对性能要求严苛的 C/C++ 代码库，例如物理模拟、渲染和游戏引擎。

CLion 现在支持 ISPC 语法，包括 uniform、varying 和 foreach 等核心构造。IDE 提供代码补全、导航和实时错误高亮显示。对于启用了 ISPC 语言的 CMake 项目，CLion 会检测 ISPC 编译器并读取其包含路径和宏。

⚙️ 无需构建系统即可获得代码洞察

当您打开一个包含单个文件的文件夹，或者您的 CMake 项目没有目标时，CLion 无法找到标准头文件。代码高亮显示、检查和代码补全工作不正常，或者根本无法工作。编辑器会显示错误的报错。

CLion 现在会自动从默认工具链的 C 和 C++ 编译器中获取头文件和宏。代码洞察立即可用。当您的构建系统提供自己的设置时，CLion 会切换为使用这些设置。
