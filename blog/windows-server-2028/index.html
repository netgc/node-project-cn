Windows Server 2028 现已推出公共预览版

随着企业业务需求不断变化并持续增长，企业基础设施也在不断演进。Windows Server 最初通过 Active Directory 将人员和资源连接起来，帮助企业实现互联。随着越来越多的业务流程转移到软件平台，它逐渐成为运行关键业务应用程序的重要平台。当这些应用程序的数量不断增加时，Hyper-V 又帮助客户更加灵活地托管其所依赖的基础设施。在每一次转型中，Windows Server 始终与客户共同发展、不断壮大。

如今，客户开始思考一个新问题：当 AI 需要与这些应用程序和数据协同工作时，应该在哪里运行？云是解决方案的一部分，但客户自行运营的本地基础设施同样重要。借助 Windows Server 2028，微软不仅进一步强化了平台现有的各项能力，还开始为企业混合智能（Enterprise Hybrid Intelligence）提供支持。

今天，微软正式推出 Windows Server 2028 公共预览版。这一重大版本进一步提升了安全性与访问控制标准，加速企业基础设施运行，并简化大规模环境下的管理工作。与此同时，微软也开始推进长期投资计划，将 Microsoft Foundry 扩展到本地 Token 工厂集群，为 AI 推理提供支持。这将让客户拥有更多选择，能够根据合适的成本结构，将适当的智能能力部署到最合适的位置。

如果您希望提前体验 Windows Server 2028 的各项功能，并与 Windows Server 工程团队直接交流，可以考虑申请加入 Windows Server 技术采用计划（Technology Adoption Program，TAP）。

实现企业混合智能

AI 带来了一个基础设施层面的关键问题：推理应该在哪里运行？

对于某些应用程序而言，云服务可能是最佳选择；而另一些应用程序则可能需要在靠近数据的位置、物理业务操作现场，或者客户能够自主控制的环境中运行推理任务。

客户需要能够自由做出这些选择，而不必为每个部署位置分别构建和运营一套独立的 AI 技术栈。同时，他们也希望能够在同一个可信赖的平台上扩展本地推理服务器，而这个平台如今已经为整个企业提供存储、计算、网络和数据库服务。

借助 Windows Server 2028，微软正在围绕企业基础设施运行推理任务所需的完整技术栈进行投资。

在硬件层，微软将为 Windows Server 2028 引入强大的新型 AI 加速器。微软很高兴地宣布，AMD 的 Instinct MI350P 加速卡即将推出预览版，预计从 2027 年上半年（H1 2027）开始，面向市场上符合支持条件的 Windows Server 设备以及 Windows Server 2028 提供支持。

详情请参阅：AMD Instinct MI350P 即将登陆 Windows：https://www.amd.com/en/blogs/2026/more-ai-more-control-amd-instinct-mi350p-comes-to-windows.html

在平台层，微软正在开发相关功能，以便部署和配置推理环境、管理加速硬件，并将模型请求定向到合适的运行环境。

在运行时层，微软正在努力支持开放权重模型（Open-weight Models）和自定义模型，涵盖的技术包括 Foundry Local、Windows ML、vLLM 和 Llama.cpp。

在企业环境中运行推理任务，也意味着必须对其进行保护和治理。

Windows Server 将受益于 Windows 在智能体（Agent）安全与管理方面的广泛投入，包括：

  • Microsoft eXecution Containers：通过隔离机制保护 AI 智能体。
  • Microsoft Foundry 集成：提供模型目录支持。
  • Agent 365：提供智能体身份管理与治理能力。

这些能力结合起来，旨在帮助客户将 AI 部署在靠近应用程序和数据的位置，同时将相关工作融入更广泛的混合 AI 架构之中。

提升安全性与访问控制标准

组织对服务器的依赖程度越高，保障服务器安全就越重要。管理员需要保护操作系统及其托管的虚拟机，维护用于保障连接安全的证书，并为基础设施整个生命周期中可能出现的各种新型威胁做好准备。而要做好这些工作，不应该要求每个团队都从零开始。

Windows Server 2028 旨在为客户提供一个更加安全可靠的起点。默认采用经过强化的 Server Core 配置，并引入全新的安全基线，从第一天起就帮助客户减少建立安全基准环境所需的工作量。Trusted Launch（可信启动） 将安全保护扩展至虚拟机，确保整个虚拟机集群的启动完整性。同时，微软开始支持 Confidential VM（机密虚拟机），逐步实现对受支持的 CVM 硬件上、具备完整性保护能力的运行时环境的支持。

此外，微软还在以下领域持续投入：

  • 自动化证书管理：解决日常安全连接维护工作中的实际需求。
  • 后量子密码学（Post-Quantum Cryptography，PQC）：应对未来量子计算威胁带来的长期安全挑战，推动密码体系现代化。

这些投入既关注日常运营中维护安全连接的任务，也着眼于未来威胁下基础设施安全能力的长期升级。

加速企业基础设施

应用程序和数据不断对底层系统提出新的要求。客户正在采用速度更快的存储技术，并处理规模越来越大的数据量。然而，这些硬件的价值能否充分发挥，取决于整个基础设施能否跟上其发展速度。

对于在 Windows Server 上运行关键工作负载的组织而言，性能提升必须能够真正惠及其现有应用程序。Windows Server 2028 默认启用原生 NVMe 存储，并支持 NVMe over TCP 和 RDMA 传输协议，同时新增从 ReFS 启动的能力。这些技术共同构成了高性能、可扩展且具备高韧性的存储解决方案，能够帮助 Windows Server 客户更充分地利用现代硬件，为高要求工作负载提供更大的发展空间。

简化大规模环境下的管理与运维

管理一台服务器，与管理整个服务器集群，是两项截然不同的工作。

在数据中心、云环境和远程站点中，IT 团队需要能够统一应用策略、管理更新，并全面了解整个基础设施中运行着哪些工作负载。而 Windows 工作负载的种类和部署环境极其多样，这进一步增加了管理难度。

微软经常听到客户提出这样的需求：希望继续使用成熟可靠的 Windows 管理流程，并将客户端和服务器作为一个统一的设备集群进行管理。

微软很荣幸能够在此前获得的服务器虚拟化领域领导者认可基础上继续前进，帮助客户实现 Windows Server 的大规模管理。

相关信息：Microsoft 被评为 2026 年 Gartner 服务器虚拟化平台魔力象限领导者

对于已经使用 Microsoft Intune 管理 Windows 客户端的团队，微软很高兴地宣布：Windows Server 的 Intune 管理功能现已进入预览阶段。

Windows Server 对 Intune 的支持，将熟悉的终端管理工作流程引入符合条件的持久化服务器，包括：

  • 配置管理
  • 合规性管理
  • 应用程序管理
  • 更新管理

与此同时，Azure 和 Azure Arc 将继续为生产环境和关键业务服务器提供云原生管理工作流程，无论这些服务器部署在哪里。当某个工作负载需要处理，或者虚拟化主机需要故障排查时，管理员需要能够深入访问计算机，了解实际运行情况。世界各地的企业客户都在大规模运行 Windows Server 虚拟机集群，因此他们需要能够跟上业务发展需求的现代化管理工具。Windows Admin Center Virtualization Mode（WAC vMode） 让管理员既能够深入管理单台服务器，也能够将虚拟化基础设施作为一个统一整体进行管理。WAC vMode 现已正式发布（GA）。

云端管理与本地部署管理并不是相互替代的关系，而是能够彼此补充。客户可以从当前最适合自身环境的工作流程开始，并在未来逐步扩展，始终使用一致的工具集。无论客户当前处于哪个阶段，都能够结合 Azure 和 Windows 管理能力，获得完整的管理体验。

未来展望

Windows Server 2028 是一个更宏大愿景的重要组成部分：让智能能力覆盖云、企业基础设施和个人设备。随着 AI 加速型工作负载逐渐普及到整个企业，不同工作负载也会呈现出不同的需求。

  • 有些工作负载需要云所提供的广泛覆盖能力和大规模计算能力。
  • 有些工作负载则需要运行在靠近关键业务应用程序和数据的位置，并部署在客户能够自主控制的基础设施上。
  • 还有一些工作负载更适合运行在人们日常使用的设备上。

成本、延迟、知识产权保护、数据驻留以及监管要求，都会影响这些部署决策。

微软的愿景是将 Microsoft Foundry 扩展到上述各种环境中，让团队能够使用熟悉的工具进行开发，并根据实际情况选择最合适的工作负载运行位置。从客户端、云端，到部署在企业数据中心中的高性能 Windows Server Token 工厂，都将成为这一架构的重要组成部分。随着 Windows Server 2028 逐步迈向正式发布（General Availability），微软将继续与客户合作，深入了解在哪些场景下，将推理任务部署在客户自己的基础设施上能够带来最大价值，并共同探索 Windows Server 如何融入更广泛的混合 AI 架构。

微软对 Windows Server 2028 所带来的可能性充满期待，也期待随着这些能力不断发展，在未来与大家分享更多进展。
