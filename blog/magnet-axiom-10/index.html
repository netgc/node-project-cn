Magnet Axiom 10.5：发掘更多证据，增强调查可信度

Magnet Axiom 10.5: Investigate more evidence with greater confidence

2026 年 11 月 3 日

Magnet Axiom 10.5.0.50473

核心要点

  • 随着数字证据不断演变，减少证据盲区。Magnet Axiom 和 Magnet Axiom Cyber 10.5 扩展了对新兴证据来源的支持，帮助调查人员发现更多相关证据，避免遗漏重要线索。

  • 构建更清晰、更经得起审查的时间线。改进的本地时间处理机制以及日期/时间筛选功能，帮助调查人员更快地重建事件经过，并确保从分析到导出整个流程中的时间上下文更加一致。

  • 以更高的可信度和灵活性开展调查。Axiom Premier 将受支持媒体文件的真实性验证功能引入安全及物理隔离环境下的工作流程；Axiom Cyber 则支持针对 macOS 和云端证据开展更符合组织自身需求的威胁分析。

技术从未停止发展。新的应用程序不断推出，通信习惯持续变化，云环境日益扩大，调查人员所依赖的证据也随之不断变化。

对于调查团队而言，跟上这些变化不仅仅意味着收集更多数据。他们还需要确认证据是否可信，在正确的上下文中查看证据，根据实际环境调整分析方式，并能够在证据存储的任何位置发现相关信息。

Magnet Axiom 10.5 和 Magnet Axiom Cyber 10.5 正是为了帮助调查人员实现这些目标。无论团队使用哪款产品，10.5 都扩展了对新兴证据来源的支持，并提供了更清晰的时间上下文。Axiom Premier 增强了媒体真实性验证的灵活性，而 Axiom Cyber 则增强了威胁分析的可定制性。

以下将介绍 Axiom 和 Axiom Cyber 新增功能。

减少证据盲区，避免遗漏重要线索

任何新的应用程序、浏览器、AI 服务或通信平台，都可能成为调查的一部分，而且往往会在调查人员预料到之前就出现。

Axiom 和 Axiom Cyber 10.5 扩展了证据覆盖范围，增加了 Signal 数据提取支持，并增强了 Discord 实时提取功能。同时，还新增或更新了对以下数据来源的支持，包括 Claude、Grok、Yahoo! Japan Browser、Safari IndexedDB、Chromium 网络缓存以及 Snapchat 搜查令返回数据。

目标很明确：随着证据环境不断变化，尽可能减少证据盲区，避免遗漏重要线索。

通过支持更多数据来源，调查团队可以将新兴证据与案件中的其他数据结合起来进行分析，从而更全面地还原事件经过。调查工作不再局限于传统的设备和应用程序证据。

将基于时间的证据转化为更清晰、经得起审查的调查时间线

一个时间戳就可能改变你对事件发生经过及发生时间的理解。但是，当调查人员需要处理路线、对话以及导出的证据时，不一致的时间上下文可能会让原本就复杂的时间线更加难以理解。

10.5 改进了路线视图、聊天线程和导出过程中的本地时间处理机制，并增加了更加清晰的日期和时间筛选功能，从而帮助调查人员更快地重建时间线，使分析结果更加经得起审查。

调查人员可以从调查开始到结束，以一致的方式审查基于时间的证据，在分析事件和与他人共享证据时减少歧义。

无论是重建对话内容、通过路线数据追踪人员活动，还是准备导出证据，更清晰的时间上下文都有助于构建连贯的事件时间线。

面向 Axiom 用户：无需将案件数据传输到安全环境之外或物理隔离环境之外，即可验证媒体证据的真实性

建立对数字媒体证据的信任比以往任何时候都更加重要。但媒体真实性验证也必须适应调查人员实际工作的方式和环境。

在 Axiom 10.5 中，Axiom Premier 扩展了由 Magnet Verify 提供支持的媒体真实性验证和来源追溯功能，使受支持文件类型能够进行离线分析。即使无法连接互联网，调查人员也可以直接在 Axiom 工作流程中评估受支持媒体文件的真实性及其来源。

通过将受支持的媒体真实性验证功能直接集成到现有 Axiom 工作流程中，调查人员可以减少在不同工具之间切换的次数。证据验证将成为调查流程中的自然环节，而不再是一个独立的操作步骤。

其结果是什么？无论调查工作在何种环境下进行，调查人员都能更加灵活地验证所依赖的证据。

面向 Axiom Cyber 用户：检测通用检测规则容易遗漏的 macOS 和云环境中的组织特定威胁

威胁分析并不存在适用于所有组织的统一方案。每个组织面临的威胁不同，所处的环境不同，因此可能需要采用不同的检测逻辑。

Axiom Cyber 10.5 为调查人员提供了更大的威胁分析控制权。

入侵指标（Indicators of Compromise，IoC）仪表板现在支持自定义 SIGMA 规则，用于 MITRE ATT&CK 分析，使团队能够应用专门针对自身环境构建的检测逻辑。MITRE ATT&CK 分析范围也扩展到了 macOS Unified Logs 和 Google Cloud Platform 日志，使调查人员能够在更多类型的证据中获得 ATT&CK 上下文信息。

对于事件响应和调查团队而言，这意味着可以将 MITRE ATT&CK 分析应用于相关的 macOS 和云端证据，而不再仅仅依赖标准分析方式，从而减少无关发现，获得更多符合组织自身环境的上下文信息和分析洞察。

更多证据 | 更清晰的上下文 | 更强的调查可信度

从本质上来说，10.5 旨在帮助调查人员跟上不断变化的证据环境，同时始终聚焦于真正重要的信息。

这些增强功能共同帮助调查团队实现以下目标：

  • 通过扩展对新兴证据来源的支持，减少证据盲区和重要线索遗漏。
  • 通过更加清晰、一致的时间上下文，更快、更有把握地重建调查时间线。
  • 借助 Axiom Premier，在无需将案件数据传输到安全环境之外或物理隔离环境之外的情况下，验证受支持媒体文件的真实性。
  • 借助 Axiom Cyber 更具适应性的威胁分析，减少无关发现，并获得更多符合组织自身需求的上下文信息和分析洞察。

因为随着数字证据持续演变，调查工作流程也必须随之发展。

Axiom 功能简介

使用 Magnet Axiom，在一个案件文件中恢复、分析并报告来自移动设备、计算机、云端和车辆的数据信息。

  • 强大的数据提取能力
  • 移动端工作流
  • 高级分析工具
  • Magnet One 增强支持

强大的数据提取能力

轻松恢复已删除的数据，并以“数据工件优先”的方式在一个案件文件中分析来自移动设备、计算机、云端和车辆的数字证据。发现文件或工件的完整历史，以构建案件并证明意图。Magnet Axiom 为最新设备和数据来源提供最及时的数据工件支持。

关键要点：

  1. 在同一案件中获取并分析来自移动设备、云端和计算机的证据。
  2. 处理来自 Google、Facebook 和 Instagram 等提供商的授权数据返回。
  3. 检查来自云端来源（如 Google、WhatsApp 等）的开源和用户账户数据。
  4. 从提取、数据恢复到案件文件构建，一步完成图像处理。

移动端工作流

无论你使用哪种提取工具，Magnet Axiom 都能获取最多的数据，并为 iOS 和 Android 设备提供最佳的分析效果。随着 Magnet Graykey 直接集成到 Axiom 中，加载移动端证据进行深度分析变得更加轻松。

关键要点：

  1. 接收并处理移动设备提取内容，直接集成 Magnet Graykey，并支持 Cellebrite、Oxygen、Berla 等第三方工具。
  2. Axiom 直观的 Mobile View 视图帮助你和相关人员在 Axiom 与 Portable Case 中轻松浏览和交互移动证据。
  3. 利用 Axiom 内强大的数据雕刻功能，发现图片、聊天记录和浏览历史。
  4. 通过 KnowledgeC、Android Motion Photos、iOS Wallet、Samsung myFiles、地理位置数据等工件，揭示详细的主体信息。
  5. 利用移动设备的令牌和钥匙串进行自动解密。

高级分析工具

通过 Magnet Axiom 的分析工具自动发现更多证据，让你专注于案件相关信息。借助 Magnet Copilot、Media Explorer、Cloud Insights Dashboard、Magnet.AI、Connections、Timeline、Email Explorer 等功能 (sysin)，快速找到所需证据。

关键要点：

  1. 使用 Magnet.AI 和 Thorn 等机器学习工具自动检测潜在的非法图片，如儿童虐待、毒品和武器内容。
  2. 使用 Connections 快速了解工件、人物或设备之间的关联。
  3. 借助 Media Explorer 从图像和视频中快速提取智能洞察。
  4. 使用 Timeline 可视化所有证据来源中的事件。
  5. 按日期、时间范围、特定工件或关键词筛选数据，快速找到相关证据。
  6. 通过早期访问 Magnet Copilot 等新 AI 工具，快速识别深度伪造媒体并提取相关证据。

借助 Magnet One 提升效率与协作

将 Axiom 与其他数字取证解决方案整合，贯穿整个工作流程，实现更快速、更高效的调查。Magnet One 可轻松简化工作流程 (sysin)，并支持取证人员、调查员、检察官、指挥人员和机构领导之间的无缝协作。

关键要点：

  1. 轻松提交数字取证实验室请求并创建案件，节省时间与精力。
  2. 通过互联的工作流程减少手动步骤，提高工作效率。
  3. 在每个阶段监控 Axiom 处理任务进度，处理完成后自动通知调查人员。
  4. 与调查团队实时协作，确保所有人都能保持同步。
